# Add the C++ source files to this folder

This folder needs the `tcl_bus` component's C++ files as well as the two
Python files already here. They live on the Home Assistant server in
`/config/esphome/components/tcl_bus/` (every `.h` and `.cpp` file there).

Copy them into this folder before committing, then delete this note.
Without them the project won't build.
